Walkthrough hero photo
======================

Place a licensed portrait here named exactly:

    aisha.jpg

Requirements / tips:
- A good-looking Indian woman portrait works best (this is "Aisha" on
  walkthrough screens 1 and 2).
- Portrait orientation, ideally around 4:5 aspect ratio (e.g. 800x1000).
  The card crops with object-cover, so faces roughly centered look best.
- Use an image you have the rights to. Free-for-commercial-use sources:
    - https://unsplash.com  (search: "indian woman portrait")
    - https://pexels.com    (search: "indian woman portrait")
  Avoid Google Images / Pinterest results — those are usually copyrighted.

If this file is missing, the card automatically falls back to the
initial-letter design, so nothing breaks.

To change the path/filename, edit FACE_AISHA in
src/pages/onboarding/Walkthrough.jsx.
